# إيماك للإستيراد والتصدير والتوريدات — IMAC

موقع شركة إيماك للتوريدات البترولية. مبني بـ **Next.js 16 (App Router) + TypeScript + Tailwind CSS v4**، **بلغتين: عربي (RTL) وإنجليزي (LTR)** مع زر تبديل اللغة في الهيدر.

---

## التشغيل

```bash
npm install
```

```bash
npm run dev
```

الموقع هيفتح على <http://localhost:3000>

```bash
npm run build
```

```bash
npm start
```

---

## اللغات

| الرابط | اللغة | الاتجاه |
| --- | --- | --- |
| `/ar` | العربية | RTL |
| `/en` | English | LTR |

أي رابط من غير بادئة لغة بيتحوّل تلقائياً — `/products` تروح `/ar/products`. والمتصفح اللي لغته إنجليزي بيروح على `/en` على طول (الإعداد في `src/middleware.ts`).

زر تبديل اللغة (أيقونة الكرة الأرضية) في الهيدر بيحافظ على نفس الصفحة — لو أنت في `/ar/products/valves` هيوديك `/en/products/valves`.

كل نصوص الواجهة في `src/lib/i18n.ts` على شكل `{ ar, en }` — عايز تغيّر أي نص، غيّره من هناك.

## تعديل البيانات

| عايز تغيّر إيه | الملف |
| --- | --- |
| التليفونات / الفاكس / الواتساب / البريد / العنوان | `src/lib/site.ts` |
| اسم ورابط الجهة المطوّرة (أسفل الفوتر) | `src/lib/site.ts` → `DEVELOPER` |
| رابط الموقع النهائي (مهم لـ SEO) | `src/lib/site.ts` → `SITE.url` |
| نصوص الواجهة (الأزرار والعناوين والقوائم) | `src/lib/i18n.ts` |
| المنتجات والمواصفات والخامات | `src/data/products.ts` |
| قائمة الكيماويات | `src/data/chemicals.ts` |
| الرؤية / الرسالة / القيم / نبذة الشركة | `src/data/content.ts` |
| أرقام الإحصائيات | `src/data/content.ts` → `STATS` |
| القطاعات وخطوات العمل | `src/data/content.ts` |
| ألوان الهوية | `src/app/globals.css` → بلوك `@theme` |
| صور الهيرو | `public/images/hero-refinery.jpg` و `hero-rig.jpg` |
| البروشور | `public/imac-brochure.pdf` |

أي نص جديد بتضيفه في `src/data/` لازم يبقى على شكل `{ ar: '...', en: '...' }`.

### إضافة شعارات العملاء

قسم شعارات العملاء في صفحة «عملاؤنا» مخفي لحد ما تضيف شعارات. حط الصور في
`public/images/clients/` وبعدين أضفها في `src/data/content.ts`:

```ts
export const CLIENT_LOGOS = [
  { name: 'اسم الشركة', logo: '/images/clients/company.png' },
]
```

القسم هيظهر تلقائياً أول ما المصفوفة تبقى مش فاضية.

## البروشور

صفحة `/[locale]/brochure` فيها:

- **عارض مدمج** على الشاشات الكبيرة (`object` مع `iframe` كبديل)
- **كارت كبير يفتح الملف** على الموبايل — لأن متصفحات الموبايل غالباً بتفتح الـ PDF في تطبيق خارجي بدل ما تعرضه جوه الصفحة
- زر **فتح في تبويب جديد** وزر **تحميل** منفصلين

كل الأزرار اللي كانت بتوديك على ملف الـ PDF مباشرةً بقت توديك على الصفحة دي.

## ملاحظات

- **نموذج التواصل** بيبعت عن طريق واتساب أو البريد الإلكتروني مباشرةً — من غير سيرفر باك-إند. لو عايز
  الرسائل تتخزن في قاعدة بيانات أو توصل على إيميل بشكل تلقائي، هيحتاج إضافة API route.
- **`SITE.url`** دلوقتي محطوط `https://www.imac-eg.com` كقيمة مبدئية — غيّرها للدومين الحقيقي قبل النشر
  علشان الـ sitemap والـ canonical والـ Open Graph يبقوا صح.
- الموقع كله **static** (44 صفحة، 22 لكل لغة) — يقدر يتنشر على Vercel أو أي استضافة بتدعم Next.js.
